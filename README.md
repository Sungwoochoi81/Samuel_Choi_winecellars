# 나의 와인 셀러 (PWA)

안드로이드 폰에 앱처럼 설치해 쓰는 개인용 와인 셀러 관리 앱입니다.

## 구성 파일

- `index.html` 앱 본체
- `manifest.webmanifest` 앱 이름, 아이콘, 전체 화면 설정
- `sw.js` 오프라인에서도 열리게 하는 서비스 워커
- `icon-*.png` 앱 아이콘
- `PretendardVariable.woff2` 글꼴 파일

## 설치 방법

1. 이 폴더의 파일을 HTTPS 주소가 있는 정적 호스팅에 올립니다. (GitHub Pages, Netlify, Cloudflare Pages 등 무료 서비스로 충분합니다.)
2. 안드로이드 크롬에서 그 주소를 엽니다.
3. 크롬 메뉴(⋮)에서 "앱 설치" 또는 "홈 화면에 추가"를 누릅니다.
4. 앱을 열고 "설정"에서 Claude API 키를 넣습니다. 키가 없어도 직접 입력과 기록은 됩니다.

## 알아 둘 점

- 와인 목록과 시음 기록은 이 폰의 브라우저 저장소에만 저장됩니다. 서버로 보내지 않습니다.
- 크롬의 "사이트 데이터 삭제"를 하면 목록도 지워집니다. 설정의 "백업 파일 저장"으로 주기적으로 백업하세요.
- API 키도 이 폰에만 저장됩니다. 라벨 인식과 와인 해설을 쓸 때만 Anthropic API로 요청이 나가며, 쓴 만큼 요금이 나옵니다.
- 파일을 새로 올리면 앱을 다음에 열 때 자동으로 새 버전이 반영됩니다.
